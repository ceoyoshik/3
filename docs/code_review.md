# Инспекция кода интеграции

## 1. Стандарты и инструменты

- Стиль: PEP 8, максимальная длина строки 79 (`.flake8`).
- Линтер: `flake8 src tests` (запускается в CI, шаг «Проверка стиля»).
- Покрытие: `coverage run --source=src -m unittest discover -s tests`,
  `coverage report --fail-under=85`.
- Совместимость: код не использует возможности новее Python 3.8.

## 2. Результаты проверки стиля

| Проверка | Правила | Результат |
| --- | --- | --- |
| Длина строки | E501 | 0 замечаний |
| Пробелы в конце строк, перевод строки в конце файла | W291, W292, W391 | 0 замечаний |
| Неиспользуемые импорты | F401 | 0 замечаний |
| Пустые строки между определениями | E302 | 0 замечаний |

Единственное исключение: `# noqa: E402` в `tests/helpers.py` — импорты
модулей проекта намеренно стоят после добавления `src/` в `sys.path`.

Покрытие `src/`: 97 % (371 исполняемая строка, 11 не выполнены в тестах —
в основном ветки `except OSError`).
